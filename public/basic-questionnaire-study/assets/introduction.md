# Introduction

Welcome to our study. 

We would like you to interact with a series of interactive data visualizations to solve a task. The task is to answer a question about the data being visualized.

The tasks work as puzzles. Sometimes the solution may not be obvious, so you should consider different ways of solving the task. If you don't know where to start, try to use the mouse on the visualization to see what happens.

There is no time limit.

Please do not use mobile devices for participating in this study.
